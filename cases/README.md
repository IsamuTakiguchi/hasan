# cases/ — 事件ワークスペース（git 管理外）

事件ごとに 1 フォルダを作る。フォルダ名は `<年>-<連番>-<識別名>`（例: `2026-008-yamada`）。

```
cases/<事件ID>/
├── input/        # 原資料を置く: 調査票・債権調査票・通帳PDF・保険証券・面談メモ・音声書き起こし等
├── work/         # 中間物: OCRテキスト、通帳の正規化CSV（bank.csv）、unzip した docx 等
├── case.yaml     # 事件モデル（唯一の真実）。hasan-intake が作成・更新する
├── questions.md  # 弁護士への確認事項（不足・矛盾項目）。hasan-intake が生成する
└── output/       # 記入済み docx/xlsx と検証用 PDF・ページ画像
```

- このフォルダ配下は `.gitignore` により**一切コミットされない**（依頼者情報保護）。
- `input/` のファイルは読み取り専用として扱い、編集しない。
- 記入済み書面の命名: `output/<書式名>_<申立人姓>_記入済み.docx`
