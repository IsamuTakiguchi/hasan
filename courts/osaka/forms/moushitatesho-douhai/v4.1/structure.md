# 破産手続開始申立書（同時廃止用）（B1102）v4.1 — 書式構造メモ

大阪地裁共通様式（同時廃止一式 ver.4.1 世代）。A4×2頁・31段落。
**w14:paraId が無い旧型式 docx** — fillmap のアンカーは context＋path＋idx の3層
（anchorlib が paraId 無しでも解決する。版更新時の照合も同様）。

## 構成

- 冒頭: タイトル・日付（idx2）・宛先（idx4、□第６民事部□堺支部□岸和田支部）
- 代理人欄（idx6〜8）: 担当弁護士名（下線）・送達場所（下線）・Tel/Fax
- 申立人欄（idx9〜15）: ふりがな・氏名/旧姓（下線2スロット）・年齢/生年月日・
  本籍（checkbox＋国籍下線）・住居所（checkbox、〒埋め込み全文置換）・連絡先
- 申立ての趣旨（印字済み・記入不要）
- 申立ての理由（idx20）: 債権者数・債務総額・保証/住宅ローン除外後額を埋め込む全文置換
- 参考事項1〜5（checkbox）: 個人事業者／法人代表者（＋その法人の破産申立て）／
  生活保護／7年内の再生認可／7年内の破産免責
- 電子納付登録コード（下線）
- ページ下部に印紙(1500円)・郵券・受領印の枠（フレーム。**触らない**）

## 登録時に判明した注意点

- run 内に複数の `<w:t>` が並ぶ段落がある（Tel行・住居所行）。fill_docx.py の
  set_run_text は先頭 w:t に全文を入れ残りを削除する仕様で対応済み。
- 申立ての理由の数値は債権者一覧表と一致必須（hasan-moushitatesho の組み立てルール参照）。
