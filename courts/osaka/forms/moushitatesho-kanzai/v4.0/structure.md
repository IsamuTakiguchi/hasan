# 破産申立書（自然人・管財事件用）（0203）v4.0 — 書式構造メモ

大阪地裁「自然人用破産申立書 ver.4.0」（管財・自然人一式）の申立書本体。
45段落・2ページ・1枚もの。B1102（同時廃止用）と同系の記入構造だが管財固有欄を持つ。
**w14:paraId が無い**ため、アンカーは context＋path＋idx で解決する。

## 構成

| 部分 | 内容 | 実装 |
|---|---|---|
| 冒頭 | 提出日・宛先「大阪地方裁判所（□　支部）御中」・代理人（下線＋印）・送達場所・TEL/FAX | set_text / checkbox / underline_fill |
| 申立人欄 | 氏名＋旧姓・通称・屋号（ふりがなは**ルビのラベル**）・年齢生年月日・本籍国籍・住所・居所・連絡先 | underline_slots / set_text / checkbox |
| 申立ての趣旨 | １破産手続開始・２自由財産拡張（財産目録の■欄参照）— **印字済み・記入不要** | — |
| 申立ての理由 | １債務の状況（一般破産債権・優先的破産債権/財団債権の総額と債権者数）・２財産の状況（回収見込額合計） | underline_slots（金額は「万」込みの下線run） |
| 必ず記載する欄 | １管財人への引継予定現金・２法人代表者か＋法人破産の係属/進行/管財人/予定・３個人事業者か・４配偶者の申立て・電子納付登録コード | checkbox / underline_slots / underline_fill |

## 登録時に判明した注意点

- **年齢・住居所・連絡先の行頭ラベルは EQ フィールド**（`eq \o\ad(年齢,…)` を
  fldChar begin〜end で囲む構造）。fill_docx の set_text はフィールド run
  （fldChar/instrText を含む run）を温存する（消すと begin/end が欠けて
  以降の文書全体が消えるレンダリング破壊になる — 登録時に実際に発生し修正済み）。
- 金額の下線 run は「＿＿万＿＿」の形で**「万」を含んで1run**。値も
  「２，２０４万５，０００」のように万込みで渡す（円は印字済み）。
- 「地方裁判所　支部　令和　年(フ)第　号，　係」は法人欄（idx35）と配偶者欄（idx41）で
  **同文が2回**現れる。idx の近接優先で解決される（fillmap の idx を正しく保つこと）。
- 数値は債権者一覧表（0209総括）・財産目録（0218総括表）と一致必須（crosscheck 対象）。
- 宛先: 本庁事件は記入不要（印字なしのため何もしない）。支部事件は「□　支部」に☑し
  支部名は提出時に手書き確認。
- ふりがな（ルビ）は機械記入不可 → 提出時に手書き案内。
