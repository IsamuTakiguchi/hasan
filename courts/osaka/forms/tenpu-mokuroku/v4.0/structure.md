# 添付目録（自然人用）（0207）v4.0 — 書式構造メモ

管財（自然人）一式の添付書類チェック目録。36段落・checkbox30個・paraId無し。
「※添付したものは□内にチェックをする。なお，下線は添付が必須である。」

構成: １資産及び負債一覧表（下線=必須・□なし）／２債権者一覧表①〜⑧／
３被課税公租公課チェック表／４財産目録①〜⑰／５リース物件一覧表／
６係属中の訴訟等一覧表／７倒産直前の処分行為等一覧表／８疎明資料目録。

fillmap は全項目 checkbox（値「添付」で☑）。**generate スキルが実際に生成・
添付した書類だけ**チェックする（生成していない書類をチェックしない）。
