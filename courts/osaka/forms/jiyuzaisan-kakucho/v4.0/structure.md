# 自由財産拡張申立書（0240）v4.0 — 書式構造メモ

18段落・paraId無しの短い申立書。ヘッダ（事件番号・申立人・日付・宛先係・
代理人・TEL/FAX）を set_text 全文置換で埋めるだけで完結。

- 申立ての趣旨: 「別添の財産目録記載の財産のうち，同財産目録の自由財産拡張申立欄に
  ■を付した財産について，破産財団に属しない財産とする。」（印字済み）
  → **財産目録（0218-0234）の自由財産拡張申立欄の■が実体**。
- 申立ての理由: 「別添の管財補充報告書第１３項記載のとおり」（印字済み）
  → 管財補充報告書（0204）の項目13の記載が前提。
- 3書類（本書・財産目録の■・補充報告書13項）の整合を必ず確認すること。
- 宛先の「第６民事部○○係」は本庁書式。支部事件は宛先を全文置換で差し替える。
