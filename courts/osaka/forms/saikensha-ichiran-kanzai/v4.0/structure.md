# 債権者一覧表・管財8シート（0209-0216）v4.0 — 書式構造メモ

1ブック8シート。総括（209）＋分類別（210借入金・211手形小切手・212買掛金・
213リース債権・214労働債権・215その他・216滞納公租公課）。

- 総括の「債権の種類」列は分類番号: 1借入金 2手形小切手 3買掛金 4リース 5労働 6その他 7公租公課
- creditors.kind → 分類: 貸金/クレジット/立替金/保証/求償→1、手形小切手→2、買掛金→3、
  リース→4、労働債権→5、公租公課→7、家賃/養育費/その他→6（備考に種類名を記載）
- 総括下部: C15=債権者数、E15=債務総額、E16=うち優先的破産債権・財団債権（労働＋公租公課）
- 210 の 別除権/保証人/契約書等/調査票等 は□セル（builder は secured/guarantor から☑）
- 214 労働債権は ①給料/②退職手当/③解雇予告手当 の内訳列（creditors[].labor から）
- 各シートに合計の数式あり（温存）。行不足時は builder が書式コピーで行挿入
- builder はヘッダ文言で列を解決する（build_kanzai_xlsx --doc saikensha-kanzai）
