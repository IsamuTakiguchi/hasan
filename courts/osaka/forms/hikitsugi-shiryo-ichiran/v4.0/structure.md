# 管財人引継資料一覧表（自然人用）（0239）v4.0 — 書式構造メモ

管財人へ引き継ぐ資料のチェック式一覧。65段落・paraId無し・末尾に注記の表1個。

記号の意味（書式末尾の注記より）:
- ◇区分ヘッダ（預貯金・保険・自動車・敷金・退職金・過払金・不動産・有価証券・
  受取手形・売掛金・貸付金・係属中の訴訟）: **財産目録に当該財産が存在する旨
  記載した場合にチェック**（→◆）。0218-0234 の記載と必ず連動させる。
- □個別資料: 管財人に引き継ぐものにチェック（→☑）。**代理人の判断事項**なので、
  スキルは判断済みのものだけ値を渡し、未判断分は questions.md へ。
- ○付き資料: 原本があってもコピーを1部作成し副本と共に管財人へ（原本は打合せ時に引継ぎ）。
- 下線付き資料（通帳・車検証・権利証等）: 申立代理人が責任をもって保管。
- △（査定書・請求書控え等）: 任意。チェック欄なし。

「５　印鑑（□実印　□銀行印）」の内訳2つの□は fillmap 未定義（必要時手書き）。
