# 管財補充報告書（0204）v4.0 — 書式構造メモ

大阪地裁「自然人用破産申立書 ver.4.0」（管財・自然人一式）の補充報告書。
180段落・6ページ・表なし。w14:paraId あり。全編がチェック欄（□→☑）と
下線記入欄で、報告書（0205）を補う管財固有の25項目を扱う。

## 登録時に判明した注意点

- 代理人欄の「印」は**別の下線run** — 値に「印」を含めない（B1102/0203 と逆）。
- 「郵便取扱局…郵便局（〒　－　）」の下線は**局名のみ**。〒欄は下線でないため
  機械記入対象外（必要時は手書き）。
- 18(4)雇用保険と18(5)社会保険の「□資格喪失届を提出していない従業員がいる。」は
  **同文**。paraId＋idx で区別する。
- 21・22 の「その理由(　)」、24 の「（場所　）」「（番号　）」は下線が無いため
  fillmap 未定義（該当時は questions.md で案内し手書き）。
- 純数字の paraId（56781654 等）は YAML で必ずクォートする（整数化すると解決に失敗）。
