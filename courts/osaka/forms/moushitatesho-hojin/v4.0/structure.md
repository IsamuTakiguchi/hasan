# 破産申立書（法人用）（0103）v4.0 — 書式構造メモ

40段落・2ページ・1枚もの。0203（自然人・管財）と同系の構造。paraId 無し。

| 部分 | 内容 | 実装 |
|---|---|---|
| 冒頭 | 提出日・宛先（□支部）・代理人（**印は下線内** — 値に印を含める）・送達場所・TEL/FAX | set_text / checkbox / underline_fill |
| 債務者欄 | 商号（ふりがなはルビ→手書き案内）・代表者・申立人（準自己破産のみ）・本店所在地（〒＋☑登記どおり）・登記と異なる場合の住所 | underline_fill / set_text |
| 趣旨 | 「債務者　＿＿について破産手続を開始する。」の下線に商号 | underline_fill |
| 理由 | 一般破産債権・優先的破産債権/財団債権の総額と債権者数・回収見込額合計（万込み下線） | underline_slots |
| 参考事項 | 引継予定現金・**代表者の破産申立て**（有無・係属・進行・管財人・予定）・電子納付 | checkbox / underline_slots |

- 数値は 0107-0114 債権者一覧表・0116-0131 財産目録と一致必須（crosscheck 対象）。
- 代表者の破産申立て「同時申立」の場合、代表者個人の管財（自然人）事件と
  相互参照（0203 側の「法人の代表者であるか」欄と整合させる）。
- 印紙は 1000円（自然人管財 0203 は 1500円）— 枠は触らない。
