# 最終の提出用フォルダの作成（破産申立て）

> パス表記: この手順は事件フォルダ方式（`受領資料/`・`作業ファイル/`・`申立書類/`・`システム/`）で書いている。
> 作業フォルダ方式・ソースリポジトリでは `cases/<事件ID>/` 配下の input/・work/・output/、`hasan/`（プラグインルート）に読み替える（対応表は事件フォルダの CLAUDE.md）。

## 前提・鉄則
- 事件フォルダの CLAUDE.md に従う。提出用フォルダは**事件フォルダの中**に作り、外へ複製しない。`システム/` は読み取り専用。
- 原本（申立書類/・受領資料/）は動かさず編集しない。提出用フォルダには**コピー**を置く。
- 裁判所書式は hasan-kit で生成済みのものを使う（自作しない）。書式が procs.yaml にあるもの（標準資料一覧表・添付目録・綴り順説明など）は hasan-kit 経由で作る。

## 1. 事前チェック（必ず実行・結果を報告）
1. `hasan-kit scan --dir .` で先生の手修正・新資料を確認し、あれば update の手順で先に反映する。
2. `hasan-kit crosscheck --case case.yaml --dir 申立書類` が全OK、`hasan-kit layout-check --dir 申立書類 --case case.yaml` が全OK。
3. questions.md の「要確認」「不足資料」「手書き箇所」を一覧にして先生に示す（未了があっても作成は進めるが、提出資料一覧に「未了」と明記する）。

## 2. フォルダ構成（日付は作成日・YYYYMMDD）
```
提出用資料_YYYYMMDD/
  00_提出資料一覧.docx          … hasan-kit memo-docx で作成（番号・書類名・頁数・原本/写し・未了/要差替）
  01_申立書類/                  … 綴り順に番号＋書式番号＋申立人名
     1_破産手続開始申立書（同時廃止用B1102）_<氏名>.docx
     2_債権者一覧表（B1105）_<氏名>.xlsx
     3_財産目録（B1109）_<氏名>.xlsx
     4_報告書（B1110）_<氏名>.docx
     5_家計収支表（B1111）_<氏名>.xlsx
     6_チェックリスト（B1114）／7_標準資料一覧表（B1103） … 未記入なら「_空欄・手記入用」と付ける
     （管財・法人は procs.yaml の書類順に合わせる）
     01_申立書類_結合.pdf
  02_添付資料/                  … 標準資料一覧表の順に番号を振る（枝番 04-1 等）
     住民票（世帯全員・本籍続柄省略なし・3か月以内）／賃貸借契約書 または 居住証明書（署名押印済み）＋建物登記／
     商業登記／債権調査票／通帳（表紙・表紙裏＋申立前１年内の取引部分、申立前2週間以内に記帳）・取引明細書／
     保険証券・解約返戻金（見込）額証明書／車検証／源泉徴収票・給与明細（直近2か月）／退職金見込額証明書（勤続5年以上）等
     02_添付資料_結合.pdf
  03_要判断_提出するか先生判断/ … 提出要否が先生判断の資料（A1… の記号）。理由をファイル名か一覧に書く
```
- ファイル名は「番号_書類名（内容・期間・日付）」で中身が分かるようにする。差替えが必要なものは「※…に差替要」と付ける。
- 通帳は標準資料４どおり表紙・表紙裏と申立前１年内の取引部分を入れる。一括記帳（合計記帳）があれば取引明細書も入れる。

## 3. PDF化と結合
- 先に pdf-layout-fix スキルの手順でフォント（IPA明朝等）を整えてから PDF にする（Word で1頁の申立書がPDFで崩れないこと）。
- docx/xlsx は `hasan-kit preview` で PDF 化、画像（jpg/png）は A4 頁に貼り込み、pymupdf で各フォルダの結合PDFを作る。
- 結合後に全頁を確認（頁数・順序・向き・崩れ・個人情報の写り込み）。
- 結合PDFは確認・送付用。裁判所提出用のPDFを作る場合は Word の「名前を付けて保存 → PDF」を推奨と添える。

## 4. 仕上げ
- 00_提出資料一覧に、手書き・押印が必要な箇所（宛先の裁判所名・提出日・連絡先・居住証明書の署名押印・委任状 等）と未了資料を書く。
- 作業ファイル/README.md に作成日・構成・作り直し手順を記録し、`hasan-kit scan --dir . --write`。

## 報告
フォルダの場所、そろった書類と未了の書類、先生に判断・手書きをお願いする箇所を簡潔に伝える。
