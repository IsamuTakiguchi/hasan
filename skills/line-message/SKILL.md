# 依頼者向けLINEメッセージ生成スキル

questions.md・不足資料リスト・面談日程から、依頼者にそのまま送れるLINE文面を作る。
**生成のみ**（LINE APIへの自動送信はしない。誤送信・守秘リスクのため必ず弁護士が
内容を確認して手動送信する）。

## 手順

1. ソースを特定: `cases/<事件ID>/questions.md`（確認事項・不足資料）、または
   利用者の指示（次回面談の案内等）。
2. 用途別テンプレ（後述）に沿って文面を作成し、**チャットに全文提示**＋
   `cases/<事件ID>/work/LINE文面_<日付>.txt` に保存。
3. 末尾に必ず「※送信前に内容をご確認ください」と、含めなかった機微事項があれば
   その旨を利用者向けに注記する（この注記は文面本体には含めない）。

## 文面のルール

- **平易な言い換え**（法律用語を使わない）:
  受任通知→「当事務所からお送りした通知」／公租公課→「税金や保険料」／
  債権者→「お借入れ先」／残高→「現在の借入額」／偏頗弁済→「特定の方への返済」／
  免責→「借金の支払義務がなくなること」／家計収支表→「家計の収支のメモ」
- **LINE向け体裁**: 1文を短く。段落は2〜3行まで。列挙は「1. 2. 3.」の番号付き。
  マークダウン記法（**太字**・# 等）は使わない。絵文字は使わない。
  敬体（です・ます）で、急かさない丁寧なトーン。
- **長文は分割**: 400字を超えるなら「【1/2】【2/2】」で分ける。
- 冒頭は名乗り＋用件の一言（例: 「○○法律事務所の△△です。書類のご準備について
  ご連絡です。」）。差出人名は利用者に確認（既定は代理人弁護士名）。

## 機微情報の防御（重要）

- **LINEに書かない**: 口座番号・借入先の一覧や金額の羅列・免責に関わる事実の指摘
  （ギャンブル等）・他の家族に見られて困る内容。
  → 「詳しくは面談でお伺いします」「お手元の書類をお持ちください」に言い換える。
- 借入先名にどうしても触れる場合は1社まで・文脈上必要な場合のみ（例: 「○○銀行から
  届いた書類」）。
- 判断に迷う内容は文面から外し、利用者への注記で「面談で直接確認することを推奨」と
  伝える。

## 用途別テンプレ

**A. 資料の追加依頼**
```
○○法律事務所の△△です。
お手続きに必要な書類のご準備をお願いいたします。

1. 通帳（すべての口座、最新まで記帳したもの）
2. 直近2か月分の給与明細
3. 保険証券（生命保険・自動車保険など）

次回の面談時にお持ちいただくか、写真を送っていただいても結構です。
ご不明な点はこのLINEでお気軽にお尋ねください。
```

**B. 確認事項の質問**（questions.md から。機微でないものだけ）
```
○○法律事務所の△△です。
書類を作成するにあたり、2点だけ確認させてください。

1. 今のお住まいの家賃は毎月いくらですか
2. お勤め先で退職金の制度はありますか

わかる範囲でご返信いただければ大丈夫です。
```

**C. 次回面談の案内・持ち物**
```
○○法律事務所の△△です。
次回の面談は下記のとおりです。

日時：9月1日（月）14時
場所：当事務所（またはお電話・Zoom）

お持ちいただくもの
1. 通帳（記帳済みのもの）
2. 家計の支出がわかるメモやレシート

ご都合が悪くなった場合は、このLINEでご連絡ください。
```

## 注意

- 事件データ（questions.md 等）は現在の作業フォルダの cases/ から読む。
- 文面ファイルも cases/<事件ID>/work/ に保存（依頼者情報のためコミット対象外）。
