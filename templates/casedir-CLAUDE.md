# 破産申立 事件フォルダ（hasan・1事件用）

このフォルダは **1つの破産事件の作業フォルダ**。破産事件に関する依頼を受けたら、
**必ず `システム/skills/` の該当スキル（SKILL.md）を読み、その手順に厳密に従うこと**。
スキルを読まずに自己流で書類を作ることを禁止する。

## このフォルダの構成（スキルのパス読み替え）

- **受領資料/** — 弁護士が原資料を入れる場所（調査票・通帳PDF・面談メモ等）
- **作業ファイル/** — Claude の中間物（聴取シート・面談メモ docx・通帳CSV・state.json）
- **申立書類/** — 生成された裁判所提出書類（Word/Excel）＋検証用PDF/画像
- **システム/** — hasan のエンジン・スキル・裁判所書式一式（読み取り専用。編集しない）

事件データは**このフォルダ直下**に置く。スキル内の `cases/<事件ID>/` という表記は、
すべて**このフォルダ直下**に読み替えること:

| スキル内の表記 | このフォルダでの実体 |
|---|---|
| cases/<事件ID>/input/ | ./受領資料/ |
| cases/<事件ID>/case.yaml | ./case.yaml（事件モデル＝唯一の真実） |
| cases/<事件ID>/questions.md | ./questions.md（弁護士への確認事項） |
| cases/<事件ID>/work/ | ./作業ファイル/ |
| cases/<事件ID>/output/ | ./申立書類/ |
| プラグインルート（hasan/） | ./システム/ |

## 既定の動き（重要）

**具体的な指示がない依頼**（「お願いします」「進めて」「続き」「チェックして」等）や、
資料・聴取シートが追加された気配があるときは、**まず update スキル**
（システム/skills/update/SKILL.md）を実行する: `システム/scripts/hasan-kit scan --dir .` で
前回からの差分（新しい受領資料・記入された聴取シート・修正）を検知し、
**Claude 側から確認質問をして** case.yaml と申立書類・聴取シートを最新化する。
利用者に「どう指示すればよいか」を考えさせないこと。

受領資料/ のファイル名が分かりにくい場合（記号・数字だけ、`IMG_0123` 等の機器既定名、
文字化け名）は、内容を確認したうえで**内容が分かる名前にリネームする**
（例: `通帳_戊田銀行_普通1234.pdf`。規約は intake スキル参照）。元の名前は
`作業ファイル/資料名変更履歴.md` に記録し、内容を特定できないものはリネームせず
確認事項に回す。

| 依頼の例 | スキル |

| 報告書を作って（自然人） | houkokusho ／ 管財補充報告書は hoju-houkokusho |

## 鉄則（スキルより先に必ず把握する）

1. **裁判所書式の出力は必ずテンプレートと同じ形式**（Excel書式→.xlsx／Word書式→.docx）。
   債権者一覧表・財産目録・資産及び負債一覧表・家計収支表・各種チェック表は **Excel**、
   申立書・報告書・目録類は **Word**（各書式の形式は
   `システム/courts/osaka/forms/<書式>/registry.yaml` の doc_type）。
2. **生成は必ず `システム/scripts/hasan-kit` 経由**（builder / fill-docx）。
   Word・Excel・Markdown を自作して代替することは禁止（裁判所書式でなくなる）。
   面談メモ・聴取シートも `hasan-kit memo-docx` による **Word（.docx）** で作る。
3. hasan-kit が失敗したら**書類を自作せず停止**し、エラー全文と
   `システム/scripts/hasan-kit doctor` の結果を利用者に報告する。
4. 手続種別（同時廃止／管財（自然人）／管財（法人））を最初に確認する（intake 参照）。
5. 生成後は `hasan-kit crosscheck --case case.yaml --dir 申立書類`（数値・出力形式の監査）と
   `hasan-kit preview`（PDF目視）まで必ず実施する。
   作業の締めに `hasan-kit scan --dir . --write` で処理済み状態を保存する
   （次回の差分検知の基準）。
6. このフォルダは依頼者情報を含む。フォルダの外へ複製しない・共有しない。

## 環境メモ

- hasan-kit の実体: `システム/scripts/hasan-kit`（このフォルダからの相対パス。
  依存パッケージは初回実行時に自動導入。診断は `システム/scripts/hasan-kit doctor`）
- システム/ はエンジン・書式一式（読み取り専用扱い。編集しない。書式改訂は
  ソースリポジトリ側で行い、システム/ を差し替える）
